API 管理平台产品手册

1. 访问令牌
访问令牌默认有效期为 24 小时。管理员可以在控制台中为服务账号创建最长 90 天的长期令牌。令牌仅在创建时完整显示一次，用户应将其保存在受控的密钥管理系统中。

2. 请求限制
标准套餐允许每个工作区每分钟 600 次请求。超过限制时，服务返回 HTTP 429，并在 Retry-After 响应头中给出建议等待秒数。

3. 审计日志
系统记录登录、令牌创建、权限变更、接口发布和数据导出操作。企业套餐的审计日志保留 365 天，标准套餐保留 30 天。

4. 故障恢复
平台每日执行一次完整备份，每小时执行增量备份。生产环境的恢复时间目标为 4 小时，恢复点目标为 1 小时。

5. 权限模型
工作区包含管理员、开发者和只读成员三种预置角色。管理员可以管理成员和密钥；开发者可以创建、测试和发布接口；只读成员只能查看接口文档和运行状态。
